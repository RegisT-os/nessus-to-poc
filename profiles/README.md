# Profiles

- `examples/` — **sanitized, committed** example profiles. Documentation IPs
  (RFC 5737) only. Safe to share.
- `private/` — **git-ignored**. Real client engagement profiles live here and
  must never be committed. Only `.gitkeep` is tracked.

See [`../docs/ENGAGEMENT_PROFILES.md`](../docs/ENGAGEMENT_PROFILES.md).
